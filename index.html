Recolorability of \((2K_2,K_4)\)-Free Graphs

This page accompanies our work on the recolorability of \((2K_2,K_4)\)-free graphs.

The project consists of two papers by Henry Echeverría and Owen Henderschedt. The first establishes several structural cases, while the second completes the problem by proving that every \((2K_2,K_4)\)-free graph is recolorable.

Computer-assisted verification

The proof of the second paper reduces a collection of repetitive finite structural calculations to attachment profiles relative to small induced cores. The verification program checks these finite calculations exhaustively.

In particular, the verifier checks the admissible attachment profiles, local neighborhood comparisons, complete lists of possible rescuers, elimination rounds, surviving profiles, and the specified induced copies of the obstruction graphs \(B_{10}\) and \(B_{11}\).

The verification is written in Python 3 and requires no external packages. It is run automatically through GitHub Actions on every update to the repository.

Verification code

The source code, certificate data, expected output, and instructions for reproducing the computation are available in the GitHub repository .

The main files are:

  • verify.py — general verification logic;
  • certificates.py — finite certificate data;
  • expected_output.txt — output of a successful verification run.

Scope of the computation

The computer verification is used only for the exhaustive finite bookkeeping in the proof. The structural lemmas, the reduction to the finite attachment problems, and the recoloring arguments are proved mathematically in the papers.
