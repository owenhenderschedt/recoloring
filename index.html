Recolorability of \((2K_2,K_4)\)-Free Graphs

This page collects two papers by Henry Echeverría and Owen Henderschedt on the recolorability of \((2K_2,K_4)\)-free graphs, together with the computer-assisted verification accompanying the second paper.

Computer-assisted verification

The code in this repository accompanies Yes, \((2K_2,K_4)\)-free graphs are recolorable. It verifies the finite attachment-profile calculations used in the proof of that paper.

More specifically, the verifier checks the admissible profiles for the finite cores appearing in the argument, the local neighborhood comparisons, the complete lists of possible rescuers, the elimination rounds and surviving profiles, and the explicit induced copies of the obstruction graphs \(B_{10}\) and \(B_{11}\).

The structural reductions and recoloring arguments are proved in the paper. The computation is used for the exhaustive finite bookkeeping arising from those reductions.

Code

The verification code, certificate data, expected output, and reproduction instructions are available in the GitHub repository .

The verifier is written in Python 3, requires no external packages, and is run automatically through GitHub Actions.
