Recolorability of \((2K_2,K_4)\)-Free Graphs

This page contains the computer-assisted verification accompanying the paper Recolorability of \((2K_2,K_4)\)-Free Graphs.

Verification

The program verifies the finite attachment-profile calculations used in the proof. In particular, it checks the admissible profiles, possible rescuers, elimination rounds, and the specified \(B_{10}\) and \(B_{11}\) obstruction certificates.

The verification code and instructions for reproducing the computation will be posted here.
